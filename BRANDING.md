# ShiftLedger visual identity

## Purpose

Keep a person's own hours and pay honestly, on their own device.

## Design system

- Maker's mark: by OBEOS. Category: WORKFORCE / 08.
- Project name: ShiftLedger.
- Accent: `#a3e635` (ledger lime).
- Canvas: `#0c1220`; primary text: `#f3f5fa`; secondary text: `#99a7bc`.
- Symbol: a clock face above two ledger lines.
- Banner: `assets/brand/github-banner.svg`, 1200 × 400; logo: `assets/logo.svg`; social preview: `assets/social-preview.png` (1280 × 640); app icons in `public/icons/`.
- Shared with the other OBEOS projects: typography, spacing, grid, footer line and the README section order. Each project keeps its own accent colour and symbol.
